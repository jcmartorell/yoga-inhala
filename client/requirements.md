## Packages
framer-motion | Complex animations for hero and scroll reveals
lucide-react | Beautiful icons for the UI
clsx | Utility for constructing className strings conditionally
tailwind-merge | Utility for merging tailwind classes

## Notes
The backend provides a single content object at `/api/content`.
Admin authentication uses a simple password-based token system stored in localStorage (handled via API).
Images are stored in `client/public/assets/` and can be referenced directly.
Google Fonts (Playfair Display and Inter) need to be imported in index.css.
